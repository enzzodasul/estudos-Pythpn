# 🐍 Curso de Python — Aulas e Exercícios

Repositório dedicado ao aprendizado e à prática da linguagem **Python**, reunindo todas as aulas, exemplos de código e exercícios desenvolvidos durante o curso.

O objetivo deste projeto é documentar minha evolução no aprendizado da programação, mantendo os conteúdos organizados e versionados para facilitar consultas, revisões e futuras implementações.

## 📚 Conteúdo do Curso

Os conteúdos estão organizados por aulas, acompanhando a sequência de aprendizado do curso.

- Introdução ao Python
- Variáveis: Integer, Float, Boolean e String
- Operadores aritméticos, de comparação e lógicos
- Estruturas de dados: Listas, Tuplas e Dicionários
- Estruturas condicionais: If, Else e Else If
- Estruturas de repetição: While e For
- Funções
- Programação Orientada a Objetos (POO)
    - Classes e Objetos
    - Encapsulamento
    - Herança
    - Polimorfismo
- Python Turtle
- Projetos práticos:
    - Balloon Popper
    - Turtle Game

## 📁 Estrutura do Repositório

Cada aula possui seu próprio arquivo Python, mantendo os códigos independentes e organizados por ordem de aprendizado.

```text
curso-python/
│
├── aulas/
│   ├── aula-01-introducao.py
│   ├── aula-02-variaveis.py
│   ├── aula-02-exercicios.py
│   ├── aula-03-variaveis.py
│   ├── aula-03-exercicios.py
│   ├── aula-04-operadores-aritmeticos.py
│   ├── ...
│   └── aula-23-turtle-game.py
│
└── README.md
```

## ▶️ Executando os Arquivos

Para executar qualquer aula, é necessário ter o Python instalado.

No terminal, navegue até a pasta do projeto e execute:

```bash
python aulas/nome-do-arquivo.py
```

## 🎯 Objetivos

- Desenvolver a lógica de programação.
- Compreender os fundamentos da linguagem Python.
- Praticar conceitos por meio de exercícios.
- Aprender os princípios da Programação Orientada a Objetos.
- Desenvolver pequenos projetos para consolidar o conhecimento.
- Registrar a evolução técnica durante o aprendizado.
